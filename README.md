# Semantique

A prompt-hopping puzzle game. Hop your doodle across a grid of word tiles to
build a sentence one token at a time — then a small open LLM judges what
emotion your sentence expresses, via logit filtering over its next-token
distribution. Hit the target emotion before your context window runs out.

Built for the **Build Small Hackathon** (Thousand Token Wood track).
